# Poojith's Movie Recommendations
Personal catalog of the 1294 titles in the "Movie Recommendations" collection. Filters (genre, type, language, years), vibe/AI search, and To watch / Watching / Watched tracking.
Status is saved in browser localStorage; optional GitHub token (Settings) syncs to `watched.json`. Optional OpenAI-compatible API key enables LLM ranking. Keys stay in the browser and never get committed.
